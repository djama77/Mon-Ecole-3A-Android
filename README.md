# Mon École 3A — Android V3

Application pédagogique Android utilisant Capacitor. Lecteur local des sept guides CRIPEN, appareil photo, reconnaissance de texte latin locale et correcteur arithmétique de base.

**Important :** il ne s'agit pas encore d'une IA multimodale capable de corriger toutes les matières. Les fichiers PDF doivent être ajoutés à `www/guides/` avant compilation complète.

Ouvrir l'onglet GitHub Actions pour compiler l'APK une fois les sept guides PDF ajoutés.
